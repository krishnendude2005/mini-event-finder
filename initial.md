# Mini Event Manager

A minimal fullstack event management system.

## Features
- List events
- View event details
- Create events
- Clean React + Express setup, typesafe, easy to extend

## Getting Started

### Backend
1. `cd backend`
2. `npm install`
3. `npm start`

### Frontend
1. (From root) `npm install`
2. `npm run start`

The frontend expects the backend server to be running at http://localhost:4000.

You can add/edit components, event types, and expand from here!
